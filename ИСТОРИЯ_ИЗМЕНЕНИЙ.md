## 2026-07-31 — Security/Resilience Hardening

### P0: Безопасность и целостность данных

- Закрыт IDOR для supplier reply: проверка `MessageOut(request_id, supplier_id)` перед привязкой ответа.
- Закрыт IDOR для employee-команд: доступ к заявке только в своей группе (или в личке владельцу заявки).
- Добавлены guard'ы статуса для `/setprice` и supplier reply (`closed/cancelled` блокируются).
- Включен constant-time compare для `X-Webhook-Secret` через `hmac.compare_digest`.
- Введена уникальность `quotes(request_id, supplier_id)` и атомарный upsert.
- Переведены денежные поля с `float` на `Decimal` в парсерах, LLM-схемах и сервисах сделок/квот.
- Усилен compose: обязательные секреты без fallback, порты только `127.0.0.1`.
- Обновлен `.env.example` новыми обязательными и эксплуатационными переменными.

### P1: Устойчивость и лимиты

- Добавлен Telegram throttle (`global + per-chat`) и retry/backoff на `429/5xx/transport`.
- Добавлен backstop rate limit middleware для `/telegram/webhook` и `/jobs/*`.
- Добавлен лимит размера HTTP body.
- Daily report теперь возвращает `sent/failed`, не падает целиком при сбое одного чата.
- Approve прайса теперь возвращает `approved_partial` при частичной публикации.
- Parser/LLM HTTP paths получили retry и лимит размера ответа.
- DB pool получил `pool_recycle` и `pool_timeout`.
- Recheck при ошибке переносится, чтобы не зациклить cron.

### P2: Качество, тесты, CI

- Введена Pydantic-модель webhook envelope.
- Добавлены новые тесты: supplier IDOR, group whitelist, inactive supplier, Telegram retry.
- Добавлены `pyproject.toml` (ruff/mypy), `.pre-commit-config.yaml`, `.github/workflows/ci.yml`.
- Зафиксированы версии зависимостей в `backend/requirements.txt`.
- Добавлен `deploy/nginx.conf.example` с rate limits и `client_max_body_size`.
