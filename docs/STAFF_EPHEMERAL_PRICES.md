# Цены поставщиков в группе — только для персонала (Ephemeral Messages)

## Зачем

В клиентской группе участвуют и сторонние люди. После первой **клиентской** цены по заявке следующие ответы поставщиков (другой поставщик, исправление, смена цены, низкая уверенность) не должны светить закупочную цену и имя поставщика всем участникам чата.

Используется [Ephemeral Messages](https://core.telegram.org/bots/features) Bot API (параметр `ephemeral_message_parameters` в `sendMessage`).

## Поведение

| Ситуация | Что видит чат | Кто ещё видит |
| --- | --- | --- |
| Первая котировка с ценой по заявке (`AUTO_PUBLISH_FIRST_VALID_PRICE=false`) | Одно обычное сообщение `supplier_quote_parsed` — только цена клиенту с наценкой | Все участники группы |
| Вторая и далее котировки, исправление цены, `price_changed`, low-confidence | Ничего публичного | Копия **ephemeral** каждому активному `employees` и каждому `owners` — шаблоны `supplier_quote_staff`, `price_changed_staff`, `supplier_low_confidence_staff` (закуп, поставщик, клиентская цена) |
| Первая клиентская цена при `AUTO_PUBLISH_FIRST_VALID_PRICE=true` | Сообщение через `telegram_outbox` (`kind='client_price'`) как раньше | Все участники; последующие котировки по-прежнему только ephemeral персоналу |

Код: `app/services/staff_ephemeral_notify.py`, вызовы из `supplier_messages`, `supplier_batch_service`, `daily_sku_price_service`.

## Требования к Telegram

1. **Бот — администратор** клиентской супергруппы. Без админки ephemeral можно отправить только в течение 15 секунд после действия пользователя; ответ поставщика приходит с задержкой.
2. Сотрудник и владелец должны быть **участниками** этой группы, иначе Telegram не доставит копию.
3. Доставка ephemeral **не гарантирована** (офлайн, перезапуск клиента). Источник правды — таблица `quotes`; сообщения в чате — уведомления.

## Уведомления вне ephemeral

- Более низкая цена после автопубликации (`notify_better_late_price`) — по-прежнему в ЛС операторам с кнопками, без изменений.
- Непривязанный ответ поставщика — только операторам (`ИЗВЕСТНЫЕ_ПРОБЛЕМЫ.md`, OPS-009).

## Проверка на staging

1. `/ask` в тестовой группе, `AUTO_PUBLISH_FIRST_VALID_PRICE=false`.
2. Первый поставщик отвечает ценой → в группе одно публичное «По вашему запросу», без имени поставщика.
3. Второй поставщик отвечает → у сотрудника и владельца в той же группе ephemeral с «Закуп» и поставщиком; у постороннего участника нового сообщения нет.
4. Исправление цены от первого поставщика → только ephemeral персоналу.

Автотесты: `backend/tests/test_staff_ephemeral_quote_notify.py`.
